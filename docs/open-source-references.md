# 开源参考

## Codex++

- 仓库：<https://github.com/BigPizzaV3/CodexPlusPlus>
- 用途：Codex 管理增强工具，安装器在选择 Codex 时默认安装。

## CC Switch

- 仓库：<https://github.com/farion1231/cc-switch>
- 用途：Claude 服务商和模型切换管理，安装器在选择 Claude 时默认安装。

## 技术栈

- Tauri v2：Win10/Win11 主安装器。
- React + TypeScript + Vite：前端向导。
- Framer Motion：页面切换和按钮反馈。
- Three.js / React Three Fiber：轻 3D 背景。
- Electron 22：Win7 兼容版本计划。
